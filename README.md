# Ertuta Galaxy S Cift Kamera APK Projesi (Otomatik Bulut Derleme)

Bu proje, Samsung Galaxy S serisi cihazlarda donanimsal olarak on ve arka kamerayi ayni anda acip ertuta.it web sayfasina canli enjekte eden Android uygulamasidir.

## Hicbir Program Kurmadan APK'yi Telefona Indirme (2 Dakika)

1. GitHub uzerinde ucretsiz bir hesap acin veya giris yapin. Sag ustteki '+' simgesine basip 'New repository' secin, isim olarak 'ertuta-apk' yazin ve olusturun.
2. Bu zip icindeki tum dosyalari GitHub reposuna surukleyip birakin ve kaydedin.
3. GitHub deposunun ust menusundeki Actions sekmesine tiklayin.
4. 'Galaxy S Cift Kamera APK Derleyici' baslikli gorev otomatik calisip 1 dakikada hazir APK dosyasini uretir.
5. Tamamlanan gorevin en altindaki 'ertuta-biometrics-galaxy-s-apk' linkinden APK'yi telefonunuza indirin ve web sunucunuza yukleyin.
