# Ertuta Biyometri - Galaxy S Cift Kamera APK Projesi

Bu proje Samsung Galaxy S serisinde on ve arka kamerayi donanim seviyesinde eszamanli acan Android uygulamasidir.

## GitHub Actions ile Otomatik Derleme:
1. Tum dosyalari GitHub reponuza yukleyin.
2. Actions sekmesinde derleme otomatik baslar.
3. Islem tamamlandiginda hazir APK dosyasini Artifacts bolumunden indirin.
